# Задача 3: Привести пример языка, являющегося VPL и LR(0), но не LL(k) ни при каком $k$.

## Пример 1: два блока одинаковых скобок

$$\boxed{L_1 = \{a^n b^n a^m b^m \mid n, m \geq 1\}}$$

### VPL ✓

Разбиение: $\Sigma_c = \{a\}$, $\Sigma_r = \{b\}$, $\Sigma_{\text{int}} = \varnothing$.

DVPA: push по $a$, pop по $b$, accept если стек пуст и прочитано два well-matched блока.

### LR(0) ✓

**Детерминированность:** DVPA выше является детерминированным.

> [!note] Беспрефиксность Структура языка: два well-matched блока подряд. Стек становится пустым **впервые** после первого блока $a^n b^n$ — эта позиция **уникально** определяет $n$. Вторая точка пустого стека определяет $m$.
> 
> Если $a^{n_1} b^{n_1} a^{m_1} b^{m_1}$ — префикс $a^{n_2} b^{n_2} a^{m_2} b^{m_2}$, то точки первого обнуления стека совпадают $\Rightarrow n_1 = n_2$, затем $m_1 = m_2$ по тому же аргументу $\Rightarrow$ слова совпадают.

### Не LL(k) ✗

> [!important] Метод подмены Фиксируем $k$. Рассмотрим:
> 
> $$w_1 = a^{n+k}\, b^{n+k}\, a\, b \qquad w_2 = a^{n}\, b^{n}\, a^{k+1}\, b^{k+1}$$
> 
> После чтения $a^n$ lookahead видит $a^k$ **в обоих случаях**. Но структурное решение разное:
> 
> - В $w_1$: первый блок ещё не закрыт, нужно читать $a$ дальше.
> - В $w_2$: первый блок закрывается сейчас ($n = n$), нужно переходить ко второму блоку.
> 
> Парсер не может отличить эти случаи — информация о том, сколько ещё `a` впереди, лежит за пределами любого конечного предпросмотра. $\blacksquare$

## Пример 2: развилка с терминатором

$$\boxed{L_2 = \{a^n b^n $ \mid n \geq 1\} \cup \{a^n c^n $ \mid n \geq 1\}}$$

### VPL ✓

Разбиение: $\Sigma_c = \{a\}$, $\Sigma_r = \{b, c\}$, $\Sigma_{\text{int}} = {\$}$.
DVPA:
- push по $a$
- pop по $b$ (переход в «$b$-режим») или по $c$ (переход в «$c$-режим»)
- смешивать $b$ и $c$ запрещено (отдельные состояния)
- по $\$$ accept, если стек пуст
### LR(0) ✓

**Беспрефиксность:** каждое слово оканчивается на $\$$, но внутри языка $\$$ никогда не встречается раньше. Плюс ветки $b$/$c$ различаются на первом символе после блока $a^n$.

### Не LL(k) ✗

> [!important] Метод подмены Фиксируем $k$. Рассмотрим:
> 
> $$w_1 = a^{n+k}\, b^{n+k}\, $ \qquad w_2 = a^{n+k}\, c^{n+k}\, $$
> 
> После чтения $a^n$ lookahead видит $a^k$ в обоих случаях. Но выбор ветки ($b$-правило или $c$-правило) можно сделать только **после** всех `a`, когда появится первый терминал $b$ или $c$.
> 
> Это точно структура ${a^n b^n} \cup {a^n c^n}$ — канонический не-LL(k) язык $\blacksquare$
