# Задача 3: Если $L$ — детерминированный КС-язык, верно ли, что $\text{Suff}(L) \in \text{DCFL}$?

## Контрпример

$$L = \{$\, a^n b^n c^m \mid n, m \geq 1\} \;\cup\; \{d, a^m b^n c^n \mid m, n \geq 1\}, \quad \Sigma = \{a,b,c,$,d\}$$

### L — ДКСЯ

ДМПА определяет режим по первому символу:

| Символ | Режим                                                            | Действие |
| ------ | ---------------------------------------------------------------- | -------- |
| $\$$   | push $a$, pop с $b$ (проверка $n = n$), затем произвольное $c^m$ |          |
| $d$    | пропуск $a^m$, push $b$, pop с $c$ (проверка $n = n$)            |          |

### Вычисление $\text{Suff}(L) \cap a^+b^+c^+$

Из $\$,a^n b^n c^m$: суффиксы вида $a^i b^n c^m$ при $1 \leq i \leq n$, т.е. $i \leq j$, $k$ произвольно.

Из $d,a^m b^n c^n$: суффиксы вида $a^i b^n c^n$ при $1 \leq i \leq m$, $m$ произвольно, т.е. $j = k$, $i$ произвольно.

$$\text{Suff}(L) \cap a^+b^+c^+ = S = \{a^i b^j c^k \mid i \leq j \;\lor\; j = k,\;\; i,j,k \geq 1\}$$

### $S$ — не ДКСЯ

> [!important] Доказательство (лемма Шаллита) Предположим $S \in \text{DCFL}$. Пусть $p$ — длина накачки. Возьмём два слова ($n \gg p$):
> 
> $$w = a^n b^n c^{n+1} \in S \quad (i \leq j) \qquad w' = a^n b^{n+1} c^{n+1} \in S \quad (j = k)$$
> 
> Общий префикс $x = a^n$, суффиксы $y = b^n c^{n+1}$ и $z = b^{n+1} c^{n+1}$ — оба начинаются с $b$. По лемме выполнено одно из двух условий.
> 
> **Условие 1** (накачка только префикса): $x = x_1 x_2 x_3$, $|x_2| \geq 1$. Накачаем вверх ($t = 2$): слово $a^{n+|x_2|} b^n c^{n+1}$. Здесь $i = n + |x_2| > n = j$ и $j = n \neq n + 1 = k$ — **не принадлежит** $S$. Противоречие. $\times$
> 
> **Условие 2** (синхронная накачка): $x_2 = a^s$, $y_2 = b^r$, $z_2 = b^q$ ($s \geq 1$).
> 
> При $t = 0$: слово $a^{n-s} b^{n-r} c^{n+1} \in S$ требует $s \geq r$ (так как $j = n - r \neq n + 1 = k$, нужно $i \leq j$).
> 
> При $t = 3$: слово $a^{n+2s} b^{n+1+2q} c^{n+1} \in S$ требует $n + 2s \leq n + 1 + 2q$ или $n + 1 + 2q = n + 1$. Второе даёт $q = 0$, тогда первое: $2s \leq 1$ — невозможно при $s \geq 1$. Противоречие. $\times$
> 
> Оба условия нарушены $\Longrightarrow$ $S \notin \text{DCFL}$. $\blacksquare$

### Завершение

ДКСЯ замкнуты относительно пересечения с регулярными языками. Если бы $\text{Suff}(L)$ был ДКСЯ, то $\text{Suff}(L) \cap a^+b^+c^+$ тоже был бы ДКСЯ. Но мы показали, что это не так.

$$\text{Suff}(L) \notin \text{DCFL} \qquad \blacksquare$$

> [!tip] Интуиция Префикс ($\$$ или $d$) определяет, **какое равенство** проверять: $i = j$ или $j = k$. Отсечение префикса уничтожает эту информацию, а стек автомата не может детерминированно угадать, в каком из двух режимов работать — возникает **существенный недетерминизм**.
